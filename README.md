# حسابات الموزع (فلاتر)

## التثبيت والتشغيل

```bash
flutter create distributor_app
```

1. افتح مجلد `distributor_app` الذي أنشأه الأمر.
2. **استبدل** ملف `pubspec.yaml` بالملف الموجود هنا.
3. **احذف** مجلد `lib` القديم وانسخ مكانه مجلد `lib` من هذا المشروع.
4. شغّل:

```bash
flutter pub get
flutter run
```

لإنشاء ملف APK لتثبيته على جوال صديقك:

```bash
flutter build apk --release
```

الملف يكون في: `build/app/outputs/flutter-apk/app-release.apk`

> إذا ظهر خطأ في `test/widget_test.dart` احذف مجلد `test`.

## الملفات

| الملف | محتواه |
|---|---|
| `lib/main.dart` | التطبيق والتنقل السفلي والمظهر |
| `lib/data.dart` | قاعدة البيانات، حساب التسديد، النسخ الاحتياطي والاسترداد |
| `lib/shops_screens.dart` | قائمة الدكاكين، تفاصيل الدكان، شاشة التوزيع |
| `lib/collect_stats.dart` | التحصيل والإحصائيات وحساب التاجر |
| `lib/settings_screens.dart` | الإعدادات وشاشة الأصناف |
| `lib/app_settings.dart` | حفظ إعدادات المظهر وحجم الخط |
| `lib/util.dart` | تنسيق الأرقام والتواريخ والنوافذ المساعدة |

## ملاحظات التصميم

- السعر يُحفظ داخل كل سطر توزيع، فتغيير سعر الصنف لا يغيّر التوزيعات القديمة.
- الكمية رقم عشري: ربع، نصف، كامل (¼ ½ 1).
- الدفعة تُسدَّد من أحدث توزيع حتى تاريخها ثم الأقدم، وما زاد يصير رصيداً للدكان.
- كل سجل له رقم فريد (UUID) وتاريخ تعديل، والحذف علامة وليس مسحاً، لذلك الدمج بين النسخ آمن.
